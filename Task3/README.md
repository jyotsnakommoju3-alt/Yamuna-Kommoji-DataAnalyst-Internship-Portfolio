## Project Overview

This project focuses on analyzing sales data to identify meaningful business insights and presenting the findings through an interactive dashboard.

## Objectives

- Analyze sales performance using key performance indicators (KPIs).
- Explore sales across products, categories, cities, and months.
- Understand customer purchasing patterns.
- Develop an interactive dashboard for data exploration.
- Present meaningful insights from the sales dataset.

## Key Performance Indicators

- Total Sales
- Unique Orders
- Average Order Value
- Units Sold
