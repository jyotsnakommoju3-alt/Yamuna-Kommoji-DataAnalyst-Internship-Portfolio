## Project overview

The internship project uses a sales dataset containing 1,000 records. The work progressed from data inspection and cleaning to exploratory analysis, dashboard development, statistical validation, and business storytelling.

### Skills demonstrated

- **Data analysis:** Excel, data cleaning, validation, exploratory data analysis
- **Querying:** SQL and SQLite
- **Programming and dashboarding:** Python, HTML, CSS, JavaScript
- **Statistics:** chi-square test, Welch's two-sample t-test, p-value interpretation
- **Communication:** data storytelling, reporting, PowerPoint, GitHub documentation

## Learning outcomes

- Prepare and validate structured sales data.
- Investigate data-quality issues and document decisions.
- Use SQL to answer business questions.
- Analyze sales by product, category, city, and month.
- Build an interactive dashboard with key performance indicators.
- Apply statistical tests and interpret results cautiously.
- Communicate findings through reports and presentations.
