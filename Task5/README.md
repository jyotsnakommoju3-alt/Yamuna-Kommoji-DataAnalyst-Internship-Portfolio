## Internship summary

1. **Task 1:** Inspected and cleaned the sales dataset, checked missing values and repeated order IDs, validated sales calculations, and prepared a cleaned workbook.
2. **Task 2:** Performed EDA in Excel and answered business questions using SQL/SQLite. Prepared an analysis workbook and report.
3. **Task 3:** Developed an interactive dashboard using HTML, CSS, and JavaScript, with KPI cards and sales views.
4. **Task 4:** Presented business insights and conducted hypothesis tests, including a chi-square test for Electronics purchase proportion by gender and Welch's t-test for average sales by gender.
5. **Task 5:** Integrated the work into a master portfolio and prepared professional communication materials.

## Skills demonstrated

- Excel: cleaning, formulas, summaries, charts, KPI reporting
- SQL/SQLite: filtering, grouping, aggregation, business queries
- Python: basic data preparation and cleaning workflow
- HTML, CSS, JavaScript: interactive dashboard development
- Statistics: hypothesis formulation, chi-square test, Welch's t-test, p-value interpretation
- Communication: data storytelling, report writing, presentations, GitHub documentation
