## Internship overview

1. **Task 1 – Data Immersion and Wrangling:** Inspected the sales dataset, checked missing values, duplicates and repeated order IDs, reviewed sales calculations, and prepared a cleaned workbook.
2. **Task 2 – EDA and SQL:** Explored sales data using Excel and answered business questions with SQL in SQLite. Prepared an analysis workbook and report.
3. **Task 3 – Interactive Dashboard:** Built a dashboard using HTML, CSS, and JavaScript, with KPI cards and sales analysis views.
4. **Task 4 – Business Insights and Statistical Testing:** Presented business insights and documented hypothesis testing and interpretation.
5. **Task 5 – Portfolio Finalization:** Organized the project documentation, created dedicated task landing pages, and linked the work from the master portfolio.

## Technical skills demonstrated

- **Excel:** data cleaning, formulas, summaries, charts, KPI reporting
- **SQL / SQLite:** filtering, grouping, aggregation, business queries
- **Python:** basic data preparation and cleaning workflow
- **HTML, CSS, JavaScript:** interactive dashboard development
- **Statistics:** hypothesis formulation, chi-square test, Welch's two-sample t-test, p-value interpretation
- **Communication:** data storytelling, report writing, presentations, GitHub documentation

## Key learnings

This internship provided practice with an end-to-end data analytics workflow: preparing data, investigating quality issues, exploring business performance, building a dashboard, using statistical methods, and communicating findings. It also reinforced the importance of documenting assumptions and interpreting results in context.
