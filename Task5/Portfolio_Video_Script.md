# Task 5 – Portfolio Walkthrough Video Script (3–5 minutes)

## 0:00–0:25 | Introduction
Hello everyone! I’m Yamuna Kommoji. In this video, I’m presenting my Data Analytics Internship portfolio completed with ApexPlanet Software Pvt. Ltd. This GitHub repository brings together my work across Tasks 1 to 5.

## 0:25–0:55 | Master GitHub portfolio
Here is my master GitHub repository. I organized the work into task-wise sections so it is easy to navigate. The main README gives an overview of the project, tools, skills, and links to each task.

## 0:55–1:35 | Task 1 – Data cleaning
In Task 1, I explored the sales dataset and worked on data quality. I checked missing values, exact duplicates, repeated order IDs, date formats, and sales calculations. I documented the cleaning decisions and prepared the cleaned dataset.

## 1:35–2:10 | Task 2 – EDA and SQL
In Task 2, I performed exploratory data analysis using Excel and answered business questions using SQL in SQLite. I analyzed sales across products, categories, cities, and months, and documented the findings.

## 2:10–2:50 | Task 3 – Interactive dashboard
In Task 3, I developed an interactive dashboard using HTML, CSS, and JavaScript. It displays KPIs such as total sales, unique orders, average order value, and units sold. It also provides views to explore sales by product, category, city, and month. I will briefly demonstrate the dashboard and its filters.

## 2:50–3:35 | Task 4 – Storytelling and statistical validation
In Task 4, I summarized business insights and applied statistical hypothesis tests. The project documentation includes a chi-square test about Electronics purchase proportions by gender and a Welch two-sample t-test comparing average sales by gender. I interpreted the p-values against a 0.05 significance level and considered limitations before drawing conclusions.

## 3:35–4:10 | Skills and learning
Through these tasks, I practiced Excel, SQL, SQLite, Python, HTML, CSS, JavaScript, dashboard development, statistical testing, data storytelling, and GitHub documentation. I also learned the importance of data quality and clear communication.

## 4:10–4:35 | Closing
This portfolio represents my learning and practical work throughout the internship. Thank you for watching. You can explore the project files through the GitHub link in the description. Thank you!
